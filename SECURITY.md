# Security

Please report a vulnerability in this site, its API service or its images to
**security@ever.co**, not in a public issue. Include what you found, how to reproduce it and the
impact you expect; we will acknowledge the report and keep you informed while we fix it.

Vulnerabilities in an Ever product itself (Ever Gauzy, Ever Teams, Ever Works, Ever Rec, Ever
Traduora, Ever Demand) go to the same address.
